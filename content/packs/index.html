Import into the console

  1. In the notification service console, open Topics and create the topic with the slug and title shown on the card.
  2. Open the topic, choose the CSV under Bulk add, then Preview import. The file has a body column, plus seq and an empty attribution.
  3. Check the preview and import. The same file also works with POST /v1/topics/:id/items:import.
