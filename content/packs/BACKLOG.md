# Topic backlog for the scheduled "topic packs" routine

Each run takes the next unused topics from this list, writes a 92-line CSV for each (one line a day for 90+ days),
and records them in `manifest.json`. A topic listed in `manifest.json` (or in `../topics.json`) is never written again.
Add ideas freely; mark nothing here by hand: `manifest.json` is the source of truth for what exists.
